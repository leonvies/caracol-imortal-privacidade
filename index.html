Política de Privacidade

Última atualização: Novembro de 2026

Leon Vies desenvolveu o aplicativo Caracol Imortal como um aplicativo gratuito suportado por anúncios. Este serviço é fornecido sem custo e destina-se ao uso como está.

1. Coleta e Uso de Informações

O aplicativo não solicita nem coleta diretamente informações de identificação pessoal (como nome, endereço ou número de telefone) dos usuários. No entanto, o aplicativo utiliza serviços de terceiros que podem coletar informações usadas para identificar o seu dispositivo.

2. Serviços de Terceiros e Anúncios

Para exibir anúncios e manter o aplicativo gratuito, utilizamos serviços de publicidade de terceiros. Esses parceiros podem coletar dados como o identificador de publicidade do dispositivo (Advertising ID), endereço IP e dados técnicos do aparelho para exibir anúncios relevantes e medir o desempenho das campanhas.

Links para as políticas de privacidade dos provedores de serviços de terceiros utilizados pelo aplicativo:

  • Google Play Services
  • Google AdMob

3. Dados de Registro (Log Data)

Em caso de erro no aplicativo, podemos coletar dados e informações (por meio de produtos de terceiros) no seu dispositivo chamados Dados de Registro. Esses dados podem incluir informações como o endereço de Protocolo de Internet (IP) do dispositivo, nome do dispositivo, versão do sistema operacional, hora e data de uso e outras estatísticas.

4. Privacidade de Crianças

Este aplicativo não coleta intencionalmente informações pessoalmente identificáveis de crianças menores de 13 anos. Caso seja identificado que dados dessa natureza foram fornecidos, eles serão removidos imediatamente.

5. Alterações nesta Política de Privacidade

Esta Política de Privacidade pode ser atualizada periodicamente. Recomenda-se revisar esta página regularmente para verificar quaisquer alterações.
